## 🔧 إعادة البناء (بعد إضافة أسئلة أو تعديلها)

```
cd "D:\TIMSS 2027\scripts"
python build_bank.py --strict      # تحقق من المخطط والرموز والمصطلحات + تحقق آلي من الإجابات + تقرير التغطية
python build_bank.py --only G2.yaml   # تحقق معزول لملف واحد (يصلح لـ PSI1.yaml وmock_X1_B1.yaml أيضاً)
python build_forms.py              # إعادة اختيار بنود الاختبار التشخيصي (بعد تعديل البنك)
python similarity_check.py mock_X1_B1.yaml   # كشف بنود الاختبارات المحمية القريبة من بنود البنك
python figure_sheets.py --topics G1 G2   # أوراق مجمّعة لرسوم البنود للفحص البصري (--psi --secure للمهام والاختبارات)
python build_platform.py           # بناء الملف الواحد (مع تشفير الاختبارات التجريبية)
python test_platform.py --codes    # اختبارات آلية + فك تشفير الاختبارات (--screens للقطات كل بند)
python build_obsidian_vault.py     # تحديث غراف المعرفة
```

**المتطلبات:** Python 3.12 مع المكتبات PyYAML وsympy وcryptography وplaywright (وكلها مثبتة على هذا الجهاز)، ومتصفح Chrome أو Edge.

## ✅ ضمان الجودة

- **تحقق آلي من كل مفتاح إجابة:** يطابق المفتاح الحل المحسوب بـ sympy، ولا مشتّت يساوي الإجابة، والترتيب والخانات والرسم تحقق شروطها.
- **تدقيق الرموز:**
  - الأرقام 0–9 فقط.
  - البدائل A–D.
  - الرياضيات داخل `$…$`.
  - لا حروف عربية داخل التعابير.
  - توحيد المصطلحات عبر `glossary.yaml`.
- **اختبارات المنصة** (Playwright، دون شبكة):
  - الحاسبة (عملية واحدة في كل مرة).
  - تصحيح كل بند بإجابته الصحيحة والخاطئة.
  - السحب والإفلات بالفأرة وبالنقر.
  - الرسم على الشبكة.
  - المحاكاة الكاملة.
  - التصدير والاستيراد.
  - فك تشفير الاختبارات.
