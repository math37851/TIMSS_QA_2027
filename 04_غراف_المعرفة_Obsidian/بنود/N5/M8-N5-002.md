# M8-N5-002

**الموضوع:** [[N5]] · **المجال:** [[الأعداد]] · **المستوى المعرفي:** [[المعرفة]] / [[تعرّف]]
**الصعوبة:** سهل · **المستوى الدولي:** [[المستوى المتوسط]] · **النوع:** [[سحب وتصنيف]] · **السياق:** رياضي مجرد

## السؤال

اسحب كل نسبة إلى المجموعة المناسبة.

**البطاقات:** $2 : 3$ · $6 : 9$ · $8 : 10$ · $10 : 15$ · $6 : 8$ · $12 : 18$

## الإجابة
$2 : 3$ ← تكافئ النسبة $4 : 6$، $6 : 9$ ← تكافئ النسبة $4 : 6$، $10 : 15$ ← تكافئ النسبة $4 : 6$، $12 : 18$ ← تكافئ النسبة $4 : 6$، $8 : 10$ ← لا تكافئ النسبة $4 : 6$، $6 : 8$ ← لا تكافئ النسبة $4 : 6$

## الحل

$4 : 6 = 2 : 3$ بقسمة الحدين على $2$. النسب المكافئة ناتجة عن ضرب الحدين في العدد نفسه: $6 : 9$ ، $10 : 15$ ، $12 : 18$.
أما $8 : 10$ و $6 : 8$ فناتجتان عن إضافة العدد نفسه إلى الحدين، وهذا لا يحافظ على النسبة.

## اقتراح علاجي

ميّز بين التفكير الضربي (صحيح) والتفكير الجمعي (خطأ): إضافة $2$ إلى الحدين ($6 : 8$) لا تحافظ على النسبة.
