# M8-A2-001

**الموضوع:** [[A2]] · **المجال:** [[الجبر]] · **المستوى المعرفي:** [[المعرفة]] / [[تعرّف]]
**الصعوبة:** متوسط الصعوبة · **المستوى الدولي:** [[المستوى المتوسط]] · **النوع:** [[سحب وتصنيف]] · **السياق:** رياضي مجرد

## السؤال

اسحب كل مقدار إلى المجموعة المناسبة.

**البطاقات:** $3x + 6$ · $3x + 2$ · $6 + 3x$ · $x + x + x + 6$ · $2(x + 3)$ · $3(2 + x)$

## الإجابة
$3x + 6$ ← مكافئ للمقدار $3(x + 2)$، $6 + 3x$ ← مكافئ للمقدار $3(x + 2)$، $x + x + x + 6$ ← مكافئ للمقدار $3(x + 2)$، $3(2 + x)$ ← مكافئ للمقدار $3(x + 2)$، $3x + 2$ ← غير مكافئ للمقدار $3(x + 2)$، $2(x + 3)$ ← غير مكافئ للمقدار $3(x + 2)$

## الحل

بتوزيع الضرب: $3(x + 2) = 3x + 6$.
المقادير $6 + 3x$ و $x + x + x + 6$ و $3(2 + x)$ تساوي جميعها $3x + 6$.
أما $3x + 2$ فنسي ضرب $2$ في $3$، و $2(x + 3) = 2x + 6$ مختلف عنه.

## اقتراح علاجي

اختبر التكافؤ بالتعويض بعدد (مثل $x = 1$): إذا اختلفت القيمتان فالمقداران غير متكافئين.
ثم استعمل نموذج المساحة (مستطيل عرضه 3 وطوله $x + 2$) لتوضيح خاصية التوزيع.
