# ✍️ مواصفات كتابة أسئلة على نمط TIMSS 2027 — رياضيات الصف الثامن

> **لمن؟** مؤلفو بنود البنك ومعلمو الرياضيات الذين يكتبون أسئلة تدريبية.
> هذا الملف هو **المرجع الملزم** لتأليف بنك المشروع. يتحقق `scripts/build_bank.py` آلياً من كثير من قواعده.

---

## 1. المبادئ العامة

1. **بند واحد = موضوع واحد + مستوى معرفي واحد** من إطار TIMSS 2027، كما في البنود الرسمية.
2. **الأصالة:** لا نسخ ولا ترجمة حرفية لبنود IEA. نستلهم الأسلوب والمستوى فقط.
3. **حياد الحاسبة:** الحاسبة متاحة في كل بنود الصف الثامن، فيُكتب البند بحيث لا تمنح الحاسبة ميزة ولا تسبب ضرراً.
4. **حمل قرائي منخفض:** جمل قصيرة، ومعلومة واحدة في كل جملة، ولا كلمات صعبة غير ضرورية.
5. **السياق:**
   - نحو 85% من البنود في سياق واقعي، نصفها تقريباً قطري: مترو الدوحة، ولوسيل، وسوق واقف، والذخيرة، والكشتة، واليوم الوطني، وأسعار بالريال، ومطار حمد.
   - نحو 15% رياضية مجردة.
6. **البيانات في السياق:** إذا كانت أرقام السياق غير حقيقية تُكتب عبارة «(بيانات افتراضية)».

## 3. المستويات المعرفية وقوالب الصياغة

| المستوى | المجال الفرعي | ما يفعله الطالب | قوالب صياغة مقترحة |
|---|---|---|---|
| **المعرفة** (35%) | تذكّر (recall) | يتذكر تعريفاً أو خاصية أو وحدة قياس | «أيّ مما يأتي يساوي…؟» «ما وحدة قياس…؟» |
| | تعرّف (identify) | يتعرف على المتكافئات، ويقرأ معلومة من رسم أو جدول | «أيّ المقادير يكافئ…؟» «ما قيمة… في الجدول؟» |
| | رتّب وصنّف (order) | يرتب الأعداد أو الأشكال أو يصنّفها حسب خاصية | «رتّب من الأصغر إلى الأكبر» «صنّف الأشكال…» |
| | احسب (compute) | ينفّذ خوارزمية مألوفة | «احسب…» «ما ناتج…؟» |
| **التطبيق** (40%) | صُغ (formulate) | يحدد العمليات والاستراتيجية المناسبة | «أيّ معادلة تمثّل…؟» «ما العملية التي تحل بها…؟» |
| | نفّذ (implement) | يطبق استراتيجية لحل مسألة في سياق | «كم ريالاً…؟» «ما ارتفاع…؟» |
| | مثّل (represent) | يمثّل البيانات أو العلاقة بجدول أو رسم أو معادلة | «ارسم…» «أكمل الجدول…» «أيّ رسم يمثّل…؟» |
| **الاستدلال** (25%) | حلّل (analyze) | يفكك المسألة ويحدد العلاقات | «أيّ العبارات صحيحة دائماً؟» «ما الذي يتغير إذا…؟» |
| | ادمج (integrate) | يربط معارف وتمثيلات مختلفة | مسائل متعددة الخطوات تجمع مجالين |
| | عمّم (generalize) | يصوغ قاعدة عامة | «اكتب قاعدة للحد النوني» «ماذا يحدث دائماً عندما…؟» |
| | برّر (justify) | يقدّم حجة رياضية | «هل … على صواب؟ وضّح إجابتك» «اختر، ثم برّر» |

## 6. كتابة البدائل (المشتّتات)

1. **كل مشتّت = مفهوم خاطئ موثّق** يُكتب تفسيره في `rationale`. أمثلة:

   | الرمز | المفهوم الخاطئ |
   |---|---|
   | `ignore-negative-sign` | تجاهل الإشارة السالبة |
   | `longer-decimal-is-larger` | «العدد العشري الأطول أكبر» |
   | `add-numerators-denominators` | جمع البسوط والمقامات |
   | `percent-wrong-base` | أساس خاطئ للنسبة المئوية |
   | `area-perimeter-confusion` | الخلط بين المساحة والمحيط |
   | `pythagoras-add-instead-of-subtract` | الجمع بدل الطرح عند إيجاد ضلع قائم |
   | `highest-value-vs-largest-increase` | الخلط بين أعلى قيمة وأكبر زيادة |
   | `mean-median-confusion` | الخلط بين المتوسط والوسيط |
   | `equiprobability-bias` | افتراض تساوي احتمالات النواتج |
   | `slope-rise-run-inverted` | قلب الميل |
2. البدائل **متجانسة** في الشكل والطول، ومرتبة منطقياً (تصاعدياً للأعداد) ما أمكن.
3. **موقع الإجابة الصحيحة** يتوزع بالتساوي تقريباً على A وB وC وD عبر البنك.
4. لا «كل ما سبق» ولا «لا شيء مما سبق».

## 8. قواعد اللغة والرموز (إلزامية)

- **النص:** عربي فصيح موجز، بمصطلحات كتب قطر (يفرضها `glossary.yaml`).
- **الأرقام:** إنجليزية دائماً (0–9). **ممنوع**: ٠١٢٣٤٥٦٧٨٩ و٪ و٫.
- **الرموز والمتغيرات والوحدات بالإنجليزية داخل `$…$`:**
  - أمثلة: `$x$` و`$3x + 6$` و`$25\%$` و`$5\,\text{m}$` و`$22\,^\circ\text{C}$` و`$\frac{3}{4}$`.
  - **لا حروف عربية داخل `$…$` إطلاقاً.**
- **العملة:** «120 ريالاً» (كلمة عربية خارج الرياضيات).
- **البدائل:** A وB وC وD.
- **الأعداد السالبة والتعابير:** داخل `$…$` دائماً (`$-6$` لا ‎-6).

## 9. قائمة التحقق قبل اعتماد البند

- [ ] البند يقيس موضوعاً واحداً ومستوى معرفياً واحداً، والوسوم صحيحة.
- [ ] الإجابة محسوبة ومُتحقق منها آلياً (`verify`)، أو بحل مستقل ثانٍ.
- [ ] لا يوجد أكثر من إجابة صحيحة، ولا غموض في الصياغة.
- [ ] كل مشتّت له تفسير (مفهوم خاطئ حقيقي).
- [ ] النص قصير وواضح ويحترم قواعد الرموز واللغة.
- [ ] الرسم (إن وجد) دقيق ومقاساته متسقة مع النص، وبه كل ما يلزم للحل.
- [ ] الحل خطوة بخطوة، والاقتراح العلاجي عملي.
- [ ] الزمن المقدّر واقعي (30–150 ثانية عادة).
